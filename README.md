# bmi_calculator_c
A simple bmi calculator project using C programming
BMI Calculator in C

A simple BMI (Body Mass Index) calculator developed using C programming.

Aim

To calculate BMI using a person's weight and height and display the corresponding adult BMI category.

Formula

BMI = Weight (kg) / Height (m)²

Features

- Accepts weight in kilograms.
- Accepts height in centimeters.
- Calculates BMI.
- Displays the BMI value.
- Displays the BMI category.
- Checks for invalid inputs.

Technologies Used

- C Programming
- Standard Input/Output Library ("stdio.h")
- Conditional Statements ("if-else")

How to Run

1. Compile the program:
   "gcc bmicalculator.c -o bmi"
2. Run the program:
   "./bmi"

On Windows PowerShell, run ".\bmi.exe" instead if you compiled it as "bmi.exe".

Sample Output

Enter weight: 60
Enter height: 155.5
BMI: 24.83
Normal weight
